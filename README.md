# chirpy
## What is it?
Chirpy is a social network RESTful API built using Go and their standard net/http package. Use it to GET, POST and DELETE users and posts(chirps). Send http request using the docs for a full coverage of all endpoints.

## Why should I care?
Having a solid backend server for a social network is a must both for security and speed. Chirpy is easy to extend and use because of Go and has a complete documentation for all endpoints and their usage.

## How to install and run
1. Clone the repo into a folder of your choosing.
2. Use go install or go run . to run the server.
3. Create a new terminal and try some endpoints by sending http request with curl
